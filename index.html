Major TOM: autonomous support triage agent

Cognida

An unattended Slack bot built on the Claude Agent SDK. It watched support channels, ran the team's debugging toolkit read-only against production, streamed its reasoning, and posted a root-cause analysis (summary, evidence, likely cause, next step). Replies in the thread resumed the session. Guardrails included a secrets-blocking hook, a per-issue USD cost cap, max turns, timeouts, a queue and AWS preflight checks. It ran in production until leadership shut it down as a priority decision.

Notification without polling

Miko · design, not built

A design for server-to-robot sync that would let robots stop polling for notifications. Each robot gets a full snapshot when its WebSocket connects, then create/update/delete deltas broadcast over Kafka to load-balanced servers. Robots keep a persisted local store, so future notifications like birthdays and reminders fire on time. The design doc covers the trade-offs and known weak spots.
